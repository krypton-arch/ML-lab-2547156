## Lab Details

### Lab1&2
Focus: Combined analysis of air quality and crop production in India.

Contents:
- Notebook for exploratory analysis and visualization
- Dataset files for air quality and crop yield
- Exported HTML and PDF reports

### Lab3
Focus: Linear regression analysis for GPA prediction and related data exploration.

Contents:
- Regression notebook and additional CIA notebooks
- Survey and mental health datasets
- Exported reports and model artifact

### Lab3_ext
Focus: Extended multiple linear regression for employee salary analysis.

- Notebook for regression modeling
- Employee salary survey dataset
- PDF report

### Lab4

Contents:
- Classification notebook and HTML report
- Breast cancer dataset
- PDF output

### Lab5
Focus: Gradient descent-based regression on student performance data.

Contents:
- Notebook for regression modeling
- HTML report and PDF export

Contents:
- Notebook for model comparison
- PDF report
